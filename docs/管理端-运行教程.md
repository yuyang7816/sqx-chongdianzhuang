# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。代码在 `cdz_admin` 文件夹。程序名称是「码上充电桩系统」。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端窗口里要已经出现「充电桩项目启动成功」，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录会失败。

## 开始之前要准备什么

安装 Node.js **18**（不要用 19 及以上）。`package.json` 的 engines 写的是 `>=18 <19`：https://nodejs.org/

这个后台用的是较老的 Webpack。`npm run dev` 会带上 `--openssl-legacy-provider`，方便在 Node 18 上跑。

安装时勾选添加到 PATH。安装完成后，重新打开 PowerShell，输入：

```powershell
node -v
npm -v
```

两行都有版本号才算成功，例如 `v18`，以及 `8.x` 以上。只看到「不是内部或外部命令」时，关掉窗口再开一次；还是没有，就重新安装 Node.js 并勾选 PATH。

浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

开发时，网页不会直接访问线上域名。`config/dev.env.js` 里 `OPEN_PROXY` 是 `true`，请求会先发到本机的 `/sqx_fast`，再由 `config/index.js` 里的代理转到真正的服务端。

用记事本打开 `cdz_admin/config/index.js`，找到 `proxyTable` 里 `/sqx_fast` 的 `target`。现在可能仍指向线上地址。改成下面这一行，原来的 `target` 可以留成注释：

```javascript
target: 'http://127.0.0.1:8174/sqx_fast/',
```

只改这一处地址。下面的 `pathRewrite` 不要动，它负责把 `/sqx_fast` 去掉再转给服务端。`port` 保持 `8001`。保存。

再打开 `cdz_admin/src/utils/httpRequest.js`。开发时代码默认走相对路径 `/sqx_fast/`，靠上面的代理转发，一般不用改 `adornUrl`。

同一个文件里的 `adornWss` 现在写死了 `wss://cdzadmin.xianmaxiong.com/wss/`。本机服务端没有这条 `wss` 转发。登录、看用户、看订单不依赖它。要在后台里测实时相关能力时，再按服务端实际的网页套接字地址改。

`static/config/index.js` 里还有一行旧地址 `http://localhost:8080/sz-fast`。开发时 `OPEN_PROXY` 为真，请求走的是上面的代理，不是这一行。只在自己电脑里 `npm run dev` 时，可以先不改它。

改完 `config/index.js` 之后，如果网站已经在运行，要先停掉再启动，修改才会生效。

## 第 2 步：安装依赖

在 `cdz_admin` 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」），执行：

```powershell
npm install
```

第一次可能要几分钟到十几分钟。结束时没有红色 `npm ERR!`，并且这个文件夹里出现 `node_modules`，就成功了。

## 第 3 步：启动网站

还是在 `cdz_admin` 文件夹里执行：

```powershell
npm run dev
```

窗口里会出现本地地址。默认端口是 **8001**，配置里 `autoOpenBrowser` 是打开的，浏览器一般会自己弹出。没有自动打开时，手动打开：

http://localhost:8001

登录页上应能看到一张验证码图片。看不清就点图片换一张。验证码来自本机服务端。图片是裂的，说明第 1 步的地址不对，或服务端没有启动。

这个 PowerShell 窗口也要一直开着。

## 怎样算成功

使用导入库里的演示账号登录。用户名是 `admin`，密码是 `123456`。登录成功后进入「数据中心」，左侧能看到菜单，例如用户中心、订单中心、店铺 / 门店列表、财务中心、系统配置。某个菜单没有出现，是这个账号的角色里没勾选它，到「角色管理」里勾上再重新登录。

> 导入库的菜单名可能仍显示「台球馆列表」等旧文案，页面内容实际是充电站门店管理。可在「菜单管理」里自行改成「充电站列表」一类名称。

门店或订单是空的，不代表后台没连上。需要先在后台录入门店，或用户端产生订单之后，这里才会有数据。

## 常见问题

**`npm` 不是内部或外部命令**  
Node.js 没装好，或安装后没有重新打开 PowerShell。

**`npm ERR!` 且提示需要 Node 18，或脚本提示当前 Node 与 webpack-dev-server 不兼容**  
`node -v` 不是 18。到 nodejs.org 安装 18 的长期支持版后再执行 `npm install`。

**浏览器打不开 localhost:8001**  
看 `npm run dev` 的窗口是否还在。窗口里如果写的是别的端口，用窗口里打印的那个地址。配置里的 `host` 是 `0.0.0.0`，本机用 `localhost` 或 `127.0.0.1` 都能开。

**验证码不显示，或登录提示网络错误**  
服务端没启动，或 `config/index.js` 的 `target` 不是 `http://127.0.0.1:8174/sqx_fast/`。按键盘 `F12`，点「网络」或 Network，再点一次登录。请求不应再发到 `cdzadmin.xianmaxiong.com`。改完后在运行窗口按 `Ctrl+C` 停掉，再执行一次 `npm run dev`。

**`Port 8001 is in use`**  
8001 已被占用。关掉之前的管理端窗口再启动。

**登录提示验证码不正确**  
图片上的字要和输入完全一致，区分大小写。点图片换一张再试。服务端窗口如果已经关掉，验证码对了也登不进去。
