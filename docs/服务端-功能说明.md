# 服务端功能说明

服务端没有给车主点的页面。它是一直开着的程序：用户端和管理端把「登录、找站、开充、付款」这些请求发给它，它检查是否允许、把结果存进数据库，必要时再去问微信、支付宝、短信这些外面的服务。

可以把它理解成总台。两个前台（用户端、管理端）说的话，都由总台记账，并在需要时给外面的公司打电话。

数据库配置在 `cdz_server/src/main/resources/application-prod.yml`。建议本机库名是 `chongdianzhuang`，导入文件是 `cdz_server/db/chongdianzhuang.sql`。充电站、充电位、订单、钱包、优惠券都记在这里。

启动类是 `com.sqx.SqxApplication`。端口是 **8174**，所有接口都在 `/sqx_fast` 下面。接口列表在：

http://127.0.0.1:8174/sqx_fast/swagger-ui.html

Redis 写在配置里，地址是本机 `6379`。当前 `spring.redis.open` 和 `sqx.redis.open` 都是关的，所以它不是必须先启动的。如果以后把开关打开，就要先启动 Redis，密码和配置文件一致。

下面先说它为两个前台做哪些事，再说它会主动连接哪些外面的服务。

## 它为充电用户做的事

这些都是用户在手机里点一下之后，由服务端完成的：

- **注册和登录**：检查手机号和短信验证码，或检查密码；也支持微信登录相关流程。通过后发给用户一张登录凭证（JWT，请求头字段名是 `token`）。之后每个请求都要带这张凭证，否则视为没登录。
- **绑定手机号、修改手机号、找回密码、修改密码**：再次核对短信或原密码，然后改资料。
- **附近充电站 / 门店**：按城市、定位返回可展示的站点列表和详情（封面、地址、营业状态、收费相关信息）。
- **扫码开充与下单**：根据站点、充电位 / 套餐生成订单，进入待支付或后续使用中状态。
- **订单**：查看订单详情、取消、续费相关字段、结束充电、退款申请等。订单状态包括待支付、待使用、使用中、已完成、已取消、待评价、待补费、挂账等。
- **我的车辆**：保存车牌与车辆信息，供常用充电使用。
- **钱包充值**：按后台配置的充值档位生成充值单；支付结果以微信或支付宝通知为准。余额支付只改数据库里的钱包数字。
- **优惠券、会员、积分**：领券、用券、开通会员、签到与积分兑换。
- **邀请**：记录邀请关系，供「邀请好友」「团队收益」一类页面显示。
- **帮助、反馈、协议、关于我们**：把后台写好的文章和协议正文发给用户端。
- **注销**：记下注销申请，交给管理端「注销信息」处理。
- **商家侧能力**：商家账号可看门店数据、充电位、商家订单、时长统计，并提交提现。

## 它为管理端做的事

- 工作人员登录，并按角色限制能看的菜单。登录验证码也由它生成。
- 提供数据中心要用的统计数字。
- 保存用户、充电站门店、充电位 / 设备、订单、公告类轮播、帮助、充值档位、优惠券。
- 订单和财务记录。退款、转账一类按钮会改订单或资金状态。原路退回微信或支付宝时，仍然要支付密钥有效。
- 审核加盟申请、用户注销。
- 保存系统配置。用户端下次请求时读到新的短信、支付、地图和图片存储配置。
- 管理员、角色、菜单、字典。

> 代码模块名仍可能叫 `tearoom` / `room` / `goods`，SQL 菜单里也可能残留「台球馆」等旧文案。业务上对应的是**充电站门店、充电位、计费套餐**。

## 对接了哪些外面的服务

下面每一项都是服务端真的会向外发送请求的。密钥没填时，它不会假装成功，用户端会看到失败提示。多数密钥保存在数据库 `common_info` 里，由管理端「系统配置」维护，不是写死在 `application.yml`。

### 短信

注册、验证码登录、找回密码、修改手机号，都由服务端发短信。

可以切换多家，在系统配置里选择服务商：

- 腾讯云短信：https://cloud.tencent.com/product/sms
- 阿里云短信：https://www.aliyun.com/product/sms
- 短信宝：https://www.smsbao.com/

短信签名和模板要在对方网站申请。只把程序跑起来，不会自动拥有短信额度。

### 微信支付

用户选择微信支付时，服务端用商户号和密钥向微信支付下单，并把拉起支付需要的信息交回手机。支付完成后，微信访问服务端的通知地址，服务端核对之后，再把订单改成已支付。

用在：充电订单、充值、会员、优惠券相关支付等。

还需要微信公众平台上的小程序或公众号 AppId：https://mp.weixin.qq.com/ 。商户平台在 https://pay.weixin.qq.com/ 。

### 支付宝

和微信同一类流程：下单、拉起支付宝、等待支付宝通知。需要支付宝开放平台的应用编号和密钥：https://open.alipay.com/ 。

### 图片存储

用户和管理端上传的图片由服务端接收，然后按「系统配置」里选中的方式保存：

- 本地上传
- 阿里云 OSS：https://www.aliyun.com/product/oss
- 腾讯云对象存储：https://www.qiniu.com/ 与 https://cloud.tencent.com/product/cos（工程里同时保留了七牛、腾讯云相关依赖）

上传方式没配好时，上传接口会失败。

### 地图

用户端定位、经纬度转城市，会用到腾讯地图或天地图一类接口，密钥在系统配置里。管理端选点使用百度地图组件，密钥在管理端前端配置。官网示例：

- 腾讯位置服务：https://lbs.qq.com/
- 百度地图开放平台：https://lbsyun.baidu.com/

### 充电设备云

门店下的充电位 / 设备会对接设备编号与设备云平台（库内可配置设备账号、密码、设备网址）。设备侧密钥同样在系统配置里维护。没配设备时，站点资料可以先维护，真正通电开充会失败。

## 这些不是外面的公司

- **余额支付**：只改数据库里的钱包数字。
- **提现**：只保存收款账号和金额，等管理端审核。没有向微信或支付宝自动打款（除非你在财务流程里另行对接并配置）。
- **收藏常用站、邀请关系、积分流水**：都在自己的数据库里。
- **站内消息 / 会话**：自己的服务器转发或落库。

## 和另外两端怎么配合

1. 先按 [服务端运行教程](服务端-运行教程.md) 把库导入并启动。
2. 管理端按 [管理端运行教程](管理端-运行教程.md) 连到本机 `8174`，用 `admin` / `123456` 登录，把系统配置里的密钥补齐。
3. 用户端按 [用户端运行教程](用户端-运行教程.md) 把 `common/config.js` 指到本机，再测找站、下单、支付。

管理端能做什么，见 [管理端功能说明](管理端-功能说明.md)。用户端每个按钮会不会连到外面，见 [用户端功能说明](用户端-功能说明.md)。
