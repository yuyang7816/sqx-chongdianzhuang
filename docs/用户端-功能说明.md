# 用户端功能说明

用户端是车主在手机或电脑网页里打开的那个应用。窗口标题是「充电桩」。底部一直有三个按钮：**首页、订单、我的**。

下面按「打开后能点到什么」来写。每一处都说明：点进去做什么，以及会不会真的连到微信、支付宝、短信这些外面的服务。

## 这个端是给谁用的

- **充电用户（车主）**：找附近充电站、看详情与收费标准、扫码开充、支付、管车辆和钱包。
- **门店商家**：在「我的」进入商家中心，看充电位、商家订单、时长与提现（需商家身份）。
- **平台工作人员不使用这个应用。** 审加盟、看财务、改轮播，在电脑上的管理端做。

## 首页

打开就是首页，标题是「充电桩」。

- **附近门店 / 站点**：按定位或城市展示可充电的门店卡片。库是空的、后台没录站，首页就是空的。
- **城市**：切换运营城市。城市数据来自管理端「城市管理」。
- **站点详情**：看封面、地址、营业状态、可充套餐 / 充电位信息。
- **收费标准**：看计费说明。
- **扫一扫**：扫设备码进入开充流程（需摄像头权限，并依赖设备与订单接口）。
- **确认支付**：选套餐或时长后进入待支付，可选余额、微信、支付宝等（以后台是否配齐为准）。

首页列表来自服务端返回的充电站数据，不是地图公司自带的兴趣点库。地图 key 主要用于定位和逆地理。

## 订单

底部「订单」是充电订单列表。点进去看订单详情：待支付、使用中、已完成等状态。

订单数据在自己的服务端。退款、结束、补费一类结果，以服务端状态为准；涉及原路退回时，仍要支付商户号有效。

## 我的

未登录时，需要先去登录。登录后显示昵称等资料。

常见入口：

- **我的车辆 / 添加车辆**：保存车牌等信息，方便常用充电。
- **我的钱包 / 充值 / 钱包明细 / 充值协议**：余额充值与流水。充值档位来自管理端「充值配置」。
- **优惠券**：平台发放的券，不是微信卡包。
- **开通会员**：读管理端配置的会员价格和特权。
- **我的积分 / 积分商城**：签到、兑换一类能力。
- **常用充电**：常去站点。
- **邀请好友**：邀请码与邀请关系，收益记在自己的数据库，不是微信自动转账。
- **帮助中心 / 意见反馈 / 客服中心**：帮助文章、反馈与客服入口。
- **设置中心**：协议、关于我们、改密、换绑手机号、注销等。

设置里常见页面：

- **隐私政策**
- **用户协议**
- **关于我们**
- **注销账号**

协议正文由后台维护。注销是提交申请，管理端「注销信息」里处理，不是点一下账号立刻从库里消失。

## 商家中心

「我的」里进入商家相关入口后，常见页面：

- **商家中心 / 我的门店**：门店概况。
- **充电位管理 / 充电位数据**：维护或查看充电位、设备相关数据。
- **商家订单 / 订单详情**：本店订单。
- **时长统计 / 收入来源详情**：经营统计。
- **商家提现 / 提现账号 / 提现记录 / 钱包明细**：提交提现，等平台审核。
- **赠送优惠券**：商家向用户发券（以后台规则为准）。

没有商家身份时，这些入口不可用或没有数据。

## 登录、注册和找回密码

登录页有手机号相关方式：

- **验证码登录或注册**：输入手机号，点获取验证码，再填收到的数字。验证码是服务端发出的短信。
- **密码登录**：手机号加密码。
- **忘记密码**：再验证一次手机号，然后设置新密码。
- **修改密码、换绑手机号**：登录后在设置里改。改手机号同样要短信验证码。
- **微信登录**：在小程序 / 相应端配置了微信 AppId 与服务端密钥后可用。

没配短信密钥，或短信签名没审核通过时，验证码发不出去，就无法用验证码注册。这时页面会停在发送失败，不是网络坏了。

## 付款

充电下单、充值或开通会员时，可选的付款方式取决于后台是否配齐：

- **余额**：扣「我的钱包」里的钱，不经过微信或支付宝。余额不够就不能选。
- **微信支付**：拉起微信支付。需要商户号、密钥，以及小程序或公众号的 AppId。
- **支付宝**：拉起支付宝。需要应用编号和密钥。

付成功后，微信或支付宝会通知服务端，订单才会变成已支付。付完钱立刻关页面、通知还没到时，订单可能要等一会儿才变。

这里没有银行卡快捷支付页面。

## 这个端真正会连到外面的服务

短信、微信、支付宝、地图、图片存储的密钥填在管理端「系统配置」，由服务端去调用。只改用户端页面上的字，不会变成已经开通。

| 你在页面上做的事 | 要申请的服务 | 官网 | 填在哪里 | 没填密钥时 |
|---|---|---|---|---|
| 注册、登录、找回密码、改手机号 | 腾讯云短信 / 阿里云短信 / 短信宝（后台选一家） | https://cloud.tencent.com/product/sms 、 https://www.aliyun.com/product/sms 、 https://www.smsbao.com/ | 管理端「系统配置」 | 验证码发不出去 |
| 微信支付 | 微信支付商户平台 | https://pay.weixin.qq.com/ | 管理端「系统配置」 | 无法拉起微信支付 |
| 微信支付还要小程序或公众号 AppId | 微信公众平台 | https://mp.weixin.qq.com/ | 管理端「系统配置」 | 只有商户号时仍然付不了 |
| 支付宝付款 | 支付宝开放平台 | https://open.alipay.com/ | 管理端「系统配置」 | 无法拉起支付宝 |
| 定位、经纬度转城市 | 腾讯位置服务或天地图等 | https://lbs.qq.com/ | 管理端「系统配置」 | 定位或城市解析失败 |
| 头像等图片上传 | 本地上传，或阿里云 OSS / 七牛 / 腾讯云 COS | https://www.aliyun.com/product/oss 等 | 管理端「系统配置」 | 上传失败 |
| 扫码真正通电开充 | 设备云 / 设备账号（按你们接入的硬件） | 以设备厂商文档为准 | 管理端「系统配置」 | 站点可浏览，开充失败 |

短信三家只用开通其中一家。图片存储按后台当前选中的方式配置。

下面这些不用申请外面的 Key，服务端和数据库就绪就能用：

- 浏览库里已经有的充电站和订单（本机联调时）。
- 用钱包余额付款。余额不够时，微信和支付宝仍要上面的密钥。
- 车辆资料、邀请关系、积分流水（记在自己库里）。
- 提现只把账号和金额交给后台审核。

界面上的按钮、输入框、弹窗，用的是 uView。它只负责长得像一个应用，不负责收款或发短信。
