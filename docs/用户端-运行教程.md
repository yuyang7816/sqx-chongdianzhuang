# 用户端运行教程

按顺序做。这是给手机和网页用的应用，窗口标题是「充电桩」。用 HBuilderX 打开 `cdz_uniapp` 文件夹来运行。

先按 [服务端运行教程](服务端-运行教程.md) 导入 `cdz_server/db/chongdianzhuang.sql` 并启动服务端。首页上的站点来自这个库（以及你在管理端录入的门店）。服务端没启动时，页面也许能打开，但列表是空的，登录会失败。

## 开始之前要准备什么

安装 HBuilderX：https://www.dcloud.io/hbuilderx.html

下载「正式版」。解压或安装后，打开软件，窗口标题是 HBuilderX，就说明安装成功。

只在电脑浏览器里看时，不需要微信开发者工具。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 1 步：确认连的是自己电脑上的服务端

用 HBuilderX 或记事本打开 `cdz_uniapp/common/config.js`。文件最上面现在可能指向线上域名。改成本机，例如：

```javascript
const ROOTPATH = "http://127.0.0.1:8174/sqx_fast";
const ROOTPATH1 = "http://127.0.0.1:8174/sqx_fast";
const WSS = "ws://127.0.0.1:8174/sqx_fast";
```

`ROOTPATH` 和 `ROOTPATH1` 是接口。`WSS` 是网页套接字。本机用 `ws://`，不要写成 `wss://`。保存文件。

文件里原来的线上地址可以留成注释，方便以后切回去。

微信小程序真机预览时，还要在微信公众平台配置合法请求域名，并在 `manifest.json` 里换成你自己的小程序 AppId。只在 HBuilderX 内置浏览器里调试本机接口时，用上面的 `127.0.0.1` 即可。

## 第 2 步：用 HBuilderX 打开工程

1. 打开 HBuilderX。
2. 菜单「文件」→「打开目录」，选中 `cdz_uniapp`（能看到 `pages.json`、`manifest.json` 的那一层）。
3. 左侧出现工程树，就说明打开对了。

## 第 3 步：运行到浏览器

在 HBuilderX 里选中 `cdz_uniapp` 工程，菜单「运行」→「运行到浏览器」→「Chrome」。

第一次可能要编译一会儿。浏览器打开后，底部应能看到三个按钮：**首页、订单、我的**。顶部或页面标题附近是「充电桩」。

首页能请求到接口时，才会显示附近门店 / 站点。库是空的、或管理端还没录门店，首页列表为空也正常。

这个 HBuilderX 和浏览器窗口可以一直开着。改了 `config.js` 之后，一般要重新运行一次。

## 第 4 步（可选）：运行到微信开发者工具

1. 先安装并打开微信开发者工具，登录你的微信账号。
2. 在 HBuilderX：「运行」→「运行到小程序模拟器」→「微信开发者工具」。
3. 若提示找不到微信开发者工具路径，到 HBuilderX 设置里填安装路径。
4. `manifest.json` 里的微信小程序 AppId 要换成你自己的，否则只能用测试号能力有限地预览。

## 怎样算成功

- 底部三个 Tab 能切换。
- 打开「我的」，可以进入登录页。
- 服务端已启动且 `config.js` 指向本机时，登录页获取验证码会真正请求服务端（短信密钥没配时会发送失败，这是配置问题，不是工程没连上）。
- 管理端已录入门店时，首页能看到站点；点进详情、扫一扫、确认支付，才进入充电下单流程。

后台演示账号是管理端用的：`admin` / `123456`。用户端需要自己注册一个手机号账号。短信、微信、支付宝、地图密钥申请入口见 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**页面能开，但一直转圈或列表空白**  
服务端没启动，或 `common/config.js` 还在指向线上域名 / 别人的内网 IP。改成 `127.0.0.1:8174` 后重新运行。

**登录收不到验证码**  
短信密钥没在管理端「系统配置」里填好，或签名模板未通过审核。先确认请求已经打到本机服务端，再去配短信。

**微信开发者工具报合法域名错误**  
小程序不能直接请求 `127.0.0.1`。开发阶段可在微信开发者工具里勾选「不校验合法域名」；正式发布必须配 https 域名。

**定位失败或城市不对**  
地图密钥未配置，或浏览器 / 小程序没有给定位权限。可先手动选城市做联调。

**扫码、支付失败**  
摄像头权限、微信 / 支付宝商户参数、或设备云未配置。浏览站点不依赖支付；真要走通开充，需要按功能说明补齐密钥与设备。
