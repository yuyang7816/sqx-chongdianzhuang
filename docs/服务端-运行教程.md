# 服务端运行教程

按顺序做。做完一步，看到文中写的成功标志，再做下一步。

服务端是三个端里要第一个启动的。代码在 `cdz_server` 文件夹。数据库不用自己建表，项目里已经带了一份导出文件：`cdz_server/db/chongdianzhuang.sql`（从当前 chongdianzhuang 库导出的演示库）。

## 开始之前要准备什么

在自己的 Windows 电脑上安装下面三个软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| JDK | 1.8（也叫 Java 8） | 开始菜单打开「命令提示符」或 PowerShell，输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 5.7 或 8.0 | 开始菜单里能找到「MySQL Command Line Client」或「MySQL 8.0 Command Line Client」 |

Java 不要装成 11、17 或 21。装错版本时，先卸掉，再装 1.8。下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

Maven 下载：https://maven.apache.org/download.cgi 。解压后把里面的 `bin` 文件夹加到 PATH。关掉原来的 PowerShell，再打开一个新的，`mvn -v` 才能看到版本。

MySQL 安装过程中会让你给 `root` 设一个密码，还会让你确认端口。把密码和端口记在纸上。Windows 上新装的 MySQL，端口通常是 **3306**。仓库里的 `application-prod.yml` 默认可能指向远程库，**第 3 步必须改成你本机的地址、端口、账号和密码**。

Redis 当前是关着的。打开 `cdz_server/src/main/resources/application.yml`，`spring.redis.open` 和 `sqx.redis.open` 都是 `false`。按本教程启动时，不必先装 Redis。以后如果把这两个开关改成 `true`，再安装 Redis，地址用 `localhost`，端口 `6379`，密码和配置文件里的 `spring.redis.password` 保持一致。

## 第 1 步：新建空数据库

这份 SQL 文件里是表和数据，它不会自己创建名叫 `chongdianzhuang` 的库。要先建库，再导入。

1. 打开开始菜单里的 MySQL 命令行。
2. 输入你安装 MySQL 时设的 root 密码，回车。看到 `mysql>` 才算连上。
3. 把下面这一整行复制进去，回车：

```sql
CREATE DATABASE IF NOT EXISTS chongdianzhuang DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

4. 再输入：

```sql
SHOW DATABASES;
```

列表里有 `chongdianzhuang` 就成功了。输入 `exit` 退出。

如果提示 `Access denied`，是密码错了，用安装 MySQL 时设的那个密码重来。

## 第 2 步：导入项目里的数据库文件

文件位置（相对整个项目文件夹）：

`cdz_server/db/chongdianzhuang.sql`

这是演示库，里面已经有表、菜单和基础配置。导入会覆盖同名的表，所以请导入到上一步新建的空库，不要导入到别的业务库。

在项目根目录（能同时看到 `cdz_server`、`cdz_admin`、`cdz_uniapp` 的那一层）打开 PowerShell。把 `-p` 后面的密码、`-P` 后面的端口，改成你的 MySQL。下面这个例子按常见本机安装来写：密码 `123456`，端口 `3306`。

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -p123456 -P3306 --default-character-set=utf8mb4 chongdianzhuang -e "source $($PWD.Path -replace '\\','/')/cdz_server/db/chongdianzhuang.sql"
```

执行时窗口会停一会儿。结束时没有 `ERROR`，再执行下面这句，能看到很多表名，就说明导入成功：

```powershell
& $mysql -uroot -p123456 -P3306 --default-character-set=utf8mb4 -e "USE chongdianzhuang; SHOW TABLES;"
```

如果提示找不到 `mysql.exe`，到 `C:\Program Files\MySQL\` 下面找到实际的 `mysql.exe`。装的是 5.7 时，路径里通常是 `MySQL Server 5.7`。把上面第一行的路径换成你的路径。

用 Navicat 也可以：连接到本机 MySQL，双击打开 `chongdianzhuang`，菜单选「运行 SQL 文件」，选中 `cdz_server/db/chongdianzhuang.sql`，编码选 UTF-8，点开始。底部显示成功即可。

## 第 3 步：让程序连接你自己的 MySQL

打开这个文件：

`cdz_server/src/main/resources/application-prod.yml`

找到数据源这几行（仓库里可能还指向远程主机，务必改成本机）：

```yaml
url: jdbc:mysql://127.0.0.1:3306/chongdianzhuang?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=CTT
username: root
password: 123456
```

说明：

- 地址用 `127.0.0.1`，库名保持 `chongdianzhuang`。
- 你的 MySQL 端口不是 3306 时，把端口改成实际端口。
- `password` 改成你安装 MySQL 时设的密码。
- **不要把别人的远程库密码写进文档或提交到公开仓库。**

保存。

再打开 `cdz_server/src/main/resources/application.yml`，确认这一行是：

```yaml
active: prod
```

是 `prod` 时，启动读的就是上面那份 `application-prod.yml`。这个项目没有单独的 `application-dev.yml`，不要去找开发配置。

## 第 4 步：启动服务端

在 `cdz_server` 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」），执行：

```powershell
mvn clean package -DskipTests
mvn spring-boot:run
```

第一次会下载很多依赖，可能要 10 到 30 分钟，窗口要一直开着。看到这行字才算启动成功：

```text
充电桩项目启动成功
```

不要关闭这个窗口。关闭后服务端就停了。

用 IDEA 也可以：

1. 用 IDEA 打开 `cdz_server`（选有 `pom.xml` 的那一层）。
2. 等右下角 Maven 导入结束。Project SDK 选 1.8。
3. 菜单「File」→「Settings」→「Plugins」，搜索并安装 Lombok，然后勾选「Enable annotation processing」。很多实体类用了 Lombok，没装插件时会报找不到 `getXxx`。
4. 打开 `src/main/java/com/sqx/SqxApplication.java`，点左侧绿色三角。
5. 控制台同样要出现「充电桩项目启动成功」。

## 怎样算成功

浏览器打开：

http://127.0.0.1:8174/sqx_fast/swagger-ui.html

能看到接口列表。页面标题附近有「sqx-fast文档」。如果这个页面打不开，只要启动日志里有「充电桩项目启动成功」，并且接下来管理端能打开登录页上的验证码图片，也算服务端已经就绪。

后台登录账号是导入库里的演示账号：用户名 `admin`，密码 `123456`。这是管理端登录密码，和 MySQL 的 root 密码不是同一件事。短信、微信、支付宝、地图、图片存储这些密钥需要自己到对应官网申请，再填进管理端「系统配置」。申请入口写在 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**`java` 不是内部或外部命令，或版本不是 1.8**  
Java 没装好，或装成了更高版本。安装 Temurin 8，关掉 PowerShell 再打开，重新执行 `java -version`。

**`mvn` 不是内部或外部命令**  
Maven 的 `bin` 没有加到 PATH。加完后必须关掉 PowerShell 再开一次。

**`Access denied for user 'root'`**  
MySQL 密码和 `application-prod.yml` 里的 `password` 不一致。把 yml 里的密码改成你安装 MySQL 时设的密码，导入命令里 `-p` 后面也改成同一个密码。

**`Communications link failure`，或提示连不上数据库**  
本机 MySQL 没有监听配置里的端口，或还在连远程主机。确认 `url` 已是 `127.0.0.1`，端口和导入命令里的 `-P` 一致，再启动。

**`Unknown database 'chongdianzhuang'`**  
第 1 步的建库没有成功。回到命令行把 `CREATE DATABASE` 再执行一次。

**导入 SQL 时中文变问号**  
命令里要带 `--default-character-set=utf8mb4`。用 Navicat 时，运行 SQL 文件的编码选 UTF-8。

**启动报找不到 `getXxx`、`setXxx` 或 `log`**  
IDEA 没装 Lombok，或没打开注解处理。按第 4 步安装插件后再编译。用 `mvn spring-boot:run` 时，Maven 会自己处理 Lombok，一般不会出现这个问题。

**`Port 8174 was already in use`**  
8174 端口已经被占用。把之前开着的服务端窗口关掉，或在任务管理器里结束对应的 Java 进程，然后再启动。

**把 Redis 开关打开之后启动失败**  
先启动 Redis，密码和 `application.yml` 里的 `spring.redis.password` 一致。不打算用缓存时，两个 `open` 保持 `false`。
